ESTRUCTURA DE CATEGORÍAS - MARBELLIN
=====================================

La carpeta categoria contiene únicamente estas tres categorías oficiales:

assets/categoria/
├── Cachetero/
├── Bikini/
└── Semihilo/

Criterios:
- Mantener los nombres de carpetas exactamente como aparecen arriba.
- Guardar cada fotografía dentro de la categoría correspondiente.
- Conservar los nombres de archivo definidos para cada producto.
- No crear las categorías "Otros" ni "Topsito".
- No eliminar ni mover imágenes existentes sin comprobar antes sus referencias en HTML, CSS y JavaScript.

Esta estructura organiza las imágenes del catálogo público. No modifica por sí sola los productos, precios, inventario ni las funciones del sitio.
